# React Payments

카드 결제 정보를 입력하고 실시간으로 카드 프리뷰를 확인할 수 있는 React 애플리케이션이다.

## 학습 목표

- 다양한 Form 구성 요소들간의 상태를 효율적으로 관리한다.
- hooks API를 이용하여 상태 관리 로직을 구현한다.
- custom hooks를 생성하여 Form 관리 로직을 컴포넌트에서 분리하고 재사용한다.
- Controlled & Uncontrolled Components에 입각하여 Form을 핸들링한다.

## 기능 요구사항

### 카드 번호 입력 및 브랜드 식별

| 브랜드     | 식별 규칙                        |
| ---------- | -------------------------------- |
| Visa       | `4`로 시작하는 16자리 숫자       |
| MasterCard | `51`~`55`로 시작하는 16자리 숫자 |
| Diners     | `36`으로 시작하는 14자리 숫자 |
| AMEX       | `34`, `37`로 시작하는 15자리 숫자 |
| 유니온페이  | `622126` ~ `622925`, `624` ~ `626`, `6282` ~ `6288`로 시작하는 15자리 숫자 |

- [v] 숫자(0~9)만 입력 가능
- [v] 4자리씩 4개의 input으로 구성
- [v] input에 카드 번호를 입력할 때마다 카드 프리뷰를 업데이트한다
- [v] 유효하지 않은 번호 입력 시 에러 피드백 제공
- [v] 다양한 카드사 지원
  - [v] Visa, Mastercard 외에 AMEX, Diners, UnionPay 등의 주요 카드사 식별 및 유효성 검사 로직 추가
  - [v] 카드 브랜드별 식별 번호 및 카드 번호 유효성 검사를 구현한다.

### 유효기간 입력

- [v] 월(MM): `01`~`12` 범위만 허용
- [v] 년(YY): `00`~`99` 범위 허용
- [v] 숫자만 입력 가능
- [v] input에 숫자를 입력할 때마다 카드 프리뷰가 업데이트된다.

### CVC 입력

- [v] `000`~`999` 범위의 3자리 숫자만 입력 가능하다.
- [v] 3자리 입력이 완료되어도 카드 프리뷰를 업데이트하지 않는다.

### 실시간 프리뷰

- [v] 카드 번호, 유효기간 입력 시 카드 프리뷰가 동시에 업데이트된다.
- [v] CVC는 프리뷰에 반영하지 않는다.
- [v] 선택한 카드사에 따라 프리뷰 카드 색이 변경된다.

### 동적 입력 UI 구현

- [v] 사용자는 카드 번호를 입력할 때 동적으로 제공되는 입력 UI를 통해 집중적으로 하나의 입력 필드에만 집중할 수 있다.
- [v] 입력 필드는 사용자의 입력이 완료되면 다음 필드로 자동으로 이동한다.

### 카드사 선택

- [v] 사용자는 카드사를 선택할 수 있고, 선택에 따라 프리뷰 카드의 색상이 변경된다.

### 폼 제출 및 상태 관리

- [v] 모든 카드 정보가 정확하게 입력되고 검증되었을 때 확인 버튼이 활성화된다.
- [v] 입력한 정보 중 하나라도 지우거나 수정하여 유효하지 않게 되면 확인 버튼은 비활성화된다.

### 카드 등록 완료 및 네비게이션

- [v] 확인 버튼을 클릭하면 사용자는 카드 등록 완료 페이지로 이동한다.
- [v] 카드 등록 완료 페이지에서는 카드 등록이 성공적으로 완료되었다는 메시지와 함께, 다시 카드 등록 페이지로 돌아갈 수 있는 확인 버튼을 제공한다.

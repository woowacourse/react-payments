# 기능 목록

## 1. 카드 번호 입력

- 입력 에러 없이 올바른 입력을 마치면, 다음 입력칸으로 포커스 이동
- 필드의 모든 입력이 올바르다면, 카드사 선택 필드가 나타나고 해당 지점으로 포커스 이동
- 사용자의 값 수정으로 인해 이전 단계에 오류가 발생해도 필드는 사라지지 않음

## 2. 카드 브랜드 미리보기

- 카드 번호에 따라 카드 브랜드 표시
- 카드 브랜드 종류 및 카드사 식별 번호 구분 규칙
  - Visa: 4로 시작하는 16자리 숫자
  - Mastercard: 51~55로 시작하는 16자리 숫자
  - AMEX: 34, 37로 시작하는 15자리 숫자
  - Diners: 36으로 시작하는 14자리 숫자
  - UnionPay
    - 622126~622925로 시작하는 16자리 숫자
    - 624~626로 시작하는 16자리 숫자
    - 6282~6288로 시작하는 16자리 숫자
- 사용자의 값 수정으로 인해 이전 단계에 오류가 발생해도 필드는 사라지지 않음

## 3. 카드사 선택

- 카드사를 선택할 수 있고, 선택에 따라 프리뷰 카드 색상 변경
- 카드사 종류
  - BC카드
  - 신한카드
  - 카카오뱅크
  - 현대카드
  - 우리카드
  - 롯데카드
  - 하나카드
  - 국민카드
- 카드사가 선택되었다면, 카드 유효기간 입력 필드 노출
- 사용자의 값 수정으로 인해 이전 단계에 오류가 발생해도 필드는 사라지지 않음

## 4. 카드 유효기간 입력

- 입력 에러 없이 올바른 입력을 마치면, 다음 입력칸으로 포커스 이동
- 필드의 모든 입력이 올바르다면, CVC 번호 입력 필드가 나타나고 해당 지점으로 포커스 이동
- 사용자의 값 수정으로 인해 이전 단계에 오류가 발생해도 필드는 사라지지 않음

## 5. CVC 번호 입력

- 입력 에러 없이 올바른 입력을 마치면, 비밀번호 입력 필드가 나타나고 해당 지점으로 포커스 이동
- 사용자의 값 수정으로 인해 이전 단계에 오류가 발생해도 필드는 사라지지 않음

## 6. 카드 비밀번호 입력

- 비밀번호 앞 2자리 입력
- 비밀번호 2자리를 입력하면, 확인 버튼으로 포커스 이동
- 사용자의 값 수정으로 인해 이전 단계에 오류가 발생해도 필드는 사라지지 않음

## 7. 카드 등록

- 모든 카드 정보가 정확하게 입력되고 검증되었을 때만 확인 버튼 활성화
- 확인 버튼을 클릭하면 카드 등록 완료 페이지로 이동

## 8. 카드 등록 완료 페이지

- 카드 등록이 성공적으로 완료되었다는 메시지 표시
- 확인 버튼을 누르면, 다시 카드 등록 페이지로 이동

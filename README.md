# 페이먼츠 미션

## 기능 요구사항

### 카드 번호 입력 및 식별

- 사용자는 카드 번호를 입력할 수 있다.
- 입력한 카드 번호에 따라 해당 브랜드의 로고가 UI에 표시된다.
- 입력한 카드 번호가 Visa, Mastercard, AMEX, Diners, UnionPay에 해당하는 경우, 해당 브랜드의 로고가 UI에 표시된다.
  - Visa: 4로 시작하는 16자리 숫자
  - MasterCard: 51~55로 시작하는 16자리 숫자
  - Diners: 36으로 시작하는 14자리 숫자
  - AMEX: 34 또는 37로 시작하는 15자리 숫자
  - UnionPay: 622126~622925, 624~626, 6282~6288로 시작하는 16자리 숫자
- 카드 번호는 양의 정수만 입력할 수 있다.
- 올바르지 않은 입력을 한 경우 피드백을 제공하고 입력을 제한한다.
- 사용자의 카드 번호 입력에 따라 카드 프리뷰를 동시에 업데이트한다.

### 카드 유효기간 입력

- 사용자는 월과 년도를 입력할 수 있다.
  - 월의 경우 1부터 12까지의 2자리의 정수이다.
  - 년도의 경우 2자리의 양의 정수이다.
  - 올바르지 않은 입력을 한 경우 피드백을 제공하고 입력을 제한한다.
- 사용자의 카드 유효기간 입력에 따라 카드 프리뷰를 동시에 업데이트한다.

### 카드 CVC 입력

- 사용자는 CVC 번호를 입력할 수 있다.
  - CVC 번호는 000 - 999 까지의 3자리 정수이다.
  - 올바르지 않은 입력을 한 경우 피드백을 제공하고 입력을 제한한다.
- 사용자의 카드 CVC 입력에 따라 카드 프리뷰를 동시에 업데이트한다.

### 동적 입력 UI

- 카드 번호 입력 단계에 따라 다음 입력칸이 현재 입력칸 위에 동적으로 표시된다.
- 입력 필드는 사용자의 입력이 완료되면 다음 필드로 자동으로 이동한다.
- 카드 브랜드의 번호 길이에 맞춰 카드 번호 입력칸 수가 동적으로 조정된다.

## 카드사 선택

- 사용자는 카드사를 선택할 수 있다.
- 선택에 따라 프리뷰 카드의 색상이 변경된다.

### 폼 제출 및 상태 관리

- 모든 카드 정보가 정확하게 입력되고 검증되었을 때만 확인 버튼이 활성화된다.

### 카드 등록 완료 및 네비게이션

- 확인 버튼을 클릭하면 사용자는 카드 등록 완료 페이지로 이동한다.
- 등록 완료 페이지에서 성공 메시지와 카드 등록 페이지로 돌아가는 확인 버튼을 제공한다.

### 카드 등록

- 등록 버튼 클릭 시 카드 정보를 전송한다.
- 정상 응답 수신 시카드 목록 페이지로 이동한다.
- 등록에 실패하면 해당 입력 필드 아래에 에러 메시지를 표시한다.

### 카드 목록

- 등록된 카드 목록을 조회한다.
- 비동기 상태에 맞는 UI를 표시한다.
  - `loading`: 스피너 또는 스켈레톤
  - `success` + 목록이 비어 있음: "등록된 카드가 없습니다" 안내
  - `success` + 목록이 있음: 카드 프리뷰 리스트
  - `error`: 에러 메시지와 재시도 버튼

### 카드 삭제

- 각 카드에 삭제 버튼을 제공한다.
- 카드 삭제 전 사용자에게 삭제 여부를 확인한다.
- 사용자가 삭제를 확인하면 해당 카드가 목록에서 제거된다.
- 사용자가 삭제를 취소하면 카드 목록은 변경되지 않는다.

# 페이먼츠 미션

우아한테크코스 레벨2 **페이먼츠** 미션 저장소이다.

이 저장소는 일부러 비어 있다. 크루는 프로젝트 부트스트랩부터 라이브러리 선택·설치·설정까지 직접 수행한다. "왜 이 라이브러리를 골랐는가"가 곧 학습이다.

## 프로젝트 초기화

[React — Build a React app from scratch](https://react.dev/learn/build-a-react-app-from-scratch)

```sh
npm create vite@latest my-app -- --template react-ts
npm install
npm run dev
```

## 기능 명세

### 카드 프리뷰

- [x] 입력한 카드 유효기간에 따라 카드 프리뷰를 실시간으로 업데이트한다.

### 카드 번호 입력 및 식별

- [x] 카드 번호를 입력 받는다.
- [x] 카드 브랜드를 식별한다.
- [x] [예외] 숫자 외의 값이 입력되는 경우
- [x] [예외] visa, mastercard 외의 번호로 시작하는 경우
- [x] [예외] 한 입력 폼의 입력된 번호의 개수가 4개 미만일 떄 포커스가 벗어난 경우
- [x] 입력한 카드 번호에 따라 카드 프리뷰를 실시간으로 업데이트한다.

### 카드 유효기간 입력

- [x] 카드 유효기간을 입력 받는다.
- [x] [예외] 숫자 외의 값이 입력되는 경우
- [x] [예외] 월, 연도 범위를 벗어난 경우
- [x] [예외] 한 입력 폼의 입력된 번호의 개수가 2개 미만일 떄 포커스가 벗어난 경우
- [x] [예외] 현재 날짜보다 과거의 날짜가 입력된 경우
- [x] 입력한 유효기간에 따라 카드 프리뷰를 실시간으로 업데이트한다.

### CVC 입력

- [x] CVC 번호를 입력 받는다.
- [x] [예외] 숫자 외의 값이 입력되는 경우
- [x] [예외] 3자리가 아닌 경우
- [x] [예외] 한 입력 폼의 입력된 번호의 개수가 3개 미만일 떄 포커스가 벗어난 경우

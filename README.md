# 페이먼츠 미션

우아한테크코스 레벨2 **페이먼츠** 미션 저장소이다.

이 저장소는 일부러 비어 있다. 크루는 프로젝트 부트스트랩부터 라이브러리 선택·설치·설정까지 직접 수행한다. "왜 이 라이브러리를 골랐는가"가 곧 학습이다.

## 프로젝트 초기화

[React — Build a React app from scratch](https://react.dev/learn/build-a-react-app-from-scratch)

```sh
npm create vite@latest my-app -- --template react-ts
npm install
npm run dev
```

## 기능 명세

### 동적 입력 UI, 카드 번호 자동 이동

**번호 자동 이동**

| 사용자 행동                        | 시스템 반응                    | 완료 |
| ---------------------------------- | ------------------------------ | ---- |
| 페이지에 진입한다                  | 첫 번째 필드가 자동 포커스된다 |      |
| 필드의 최대 자릿수를 채운다        | 다음 필드로 포커스가 이동한다  |      |
| 빈 필드에서 Backspace를 누른다     | 이전 필드로 포커스가 이동한다  |      |
| 마지막 필드의 최대 자릿수를 채운다 | • 포커스가 이동하지 않는다     |
| • 카드사 선택 섹션이 렌더링된다    |                                |

### 카드 브랜드 구분 (입력)

| 사용자 행동                              | 시스템 반응                                     | 완료 |
| ---------------------------------------- | ----------------------------------------------- | ---- |
| 36으로 시작하는 14자리 숫자를 입력한다   | 카드 프리뷰에 Diners의 브랜드 로고가 렌더링된다 |      |
| 34, 37로 시작하는 15자리 숫자를 입력한다 | 카드 프리뷰에 AMEX 브랜드 로고가 렌더링된다     |      |
| 카드의 앞 번호가 아래의 3가지 조건을 만족하는 16자리 숫자를 입력한다 (• 622126~622925로 시작 • 624~626로 시작 • 6282~6288로 시작) | 카드 프리뷰에 유니온페이 브랜드 로고가 렌더링된다 | |
| 어떤 브랜드에도 해당하지 않는 번호를 입력한다 | 브랜드 로고가 렌더링되지 않는다 | |

### 카드사 선택

| 사용자 행동 | 시스템 반응 | 완료 |
| ----------- | ----------- | ---- |
| (선택한 카드사가 없는 경우) 드롭다운을 열고 특정 카드사를 선택한다 | 1. 선택한 카드사의 UI가 0.3s간 활성화된다 2. 0.3s 후 드롭다운이 닫히며 선택된 카드사의 이름이 트리거에 렌더링된다 3. ‘유효기간’ 섹션이 렌더링된다 4. 카드사에 맞게 프리뷰 카드의 색상이 렌더링된다 | |
| (이미 선택한 카드사가 있는 경우) 드롭다운을 연다 | 기존에 선택한 카드사가 활성화 표시된 채로 열린다. | |
| (이미 선택한 카드사가 있는 경우) 드롭다운을 열고 이미 선택한 카드사를 선택한다 | 드롭다운을 닫지 않는다 | |
| (이미 선택한 카드사가 있는 경우) 드롭다운을 열고 이미 선택한 카드사 외의 카드사를 선택한다 | 1. 선택한 카드사의 UI가 0.3s간 활성화된다 2. 0.3s 후 드롭다운이 닫히며 선택된 카드사의 이름이 트리거에 렌더링된다 3. ‘유효기간’ 섹션이 렌더링된다 | |

### 폼 제출

**확인 버튼 활성화 조건**

| 조건                                      | 시스템 반응              | 완료 |
| ----------------------------------------- | ------------------------ | ---- |
| 모든 필드가 유효한 값으로 채워진 경우     | 확인 버튼이 활성화된다   |      |
| 하나라도 유효하지 않은 값이 존재하는 경우 | 확인 버튼이 비활성화된다 |      |

**폼 제출**

| 사용자 행동                                 | 시스템 반응                      | 완료 |
| ------------------------------------------- | -------------------------------- | ---- |
| (버튼 활성 상태에서) 확인 버튼을 누른다     | 카드 등록 완료 페이지로 이동한다 |      |
| (버튼 비활성화 상태에서) 확인 버튼을 누른다 | 무반응                           |      |

### 네비게이션

| 사용자 행동                                                 | 시스템 반응                                  | 완료 |
| ----------------------------------------------------------- | -------------------------------------------- | ---- |
| 카드 등록 완료 페이지에 진입한다 | 카드 등록이 성공적으로 완료되었다는 메시지와 다시 카드 등록 페이지로 돌아갈 수 있는 확인 버튼을 제공한다 | |
| 카드 등록 페이지로 돌아가는 버튼을 클릭한다 | 카드 등록 페이지로 돌아간다 | |

### 에러 UX

| 사용자 행동                                                      | 시스템 반응                                           | 완료 |
| ---------------------------------------------------------------- | ----------------------------------------------------- | ---- |
| 숫자 이외의 문자를 입력한다                                      | 입력이 무시된다                                       |      |
| 아무것도 입력하지 않은 상태에서 해당 입력창을 떠난다             | 무반응 (에러를 띄우지 않는다)                         |      |
| (해당 필드의 최대 조건을 만족하는) O자 미만의 숫자를 입력 중이다 | 무반응 (에러를 띄우지 않는다)                         |      |
| 4자 미만의 숫자를 입력한 상태에서 해당 입력창을 떠난다           | “숫자는 O자리를 입력해야 합니다” 에러 메시지를 띄운다 |      |
| 에러가 발생한 입력 필드에 포커스한다                             | 입력 필드에 해당하는 에러 메시지를 띄운다             |      |

# 페이먼츠 미션

## 기능 요구 사항

### 카드 번호 입력 및 식별

- [ ] 카드 번호는 4자리씩 4개의 input으로 입력받는다
- [ ] 입력은 숫자만 가능하고 유효하지 않은 번호 입력시 피드백을 제공한다.

### 카드 유효기간 입력

- [ ] 카드 유효기간은 월 2자리와 년도 2자리를 각각 별도의 input으로 입력받는다.
- [ ] 입력은 유효한 월과 년도만 입력가능하도록 제한한다.

### CVC

- [ ] CVC는 숫자 3자리만 입력 가능하다.
- [ ] 유효하지 않은 번호 입력시 제한한다.

### 실시간 프리뷰 업데이트

- [ ] 사용자가 입력하는 카드 번호를 실시간으로 파악하여 VISA나 MasterCard에 해당하면 해당 브랜드 UI에 표시한다.

## 프로그래밍 요구 사항

- [ ] Storybook을 이용하여 컴포넌트의 다양한 상태를 테스트한다.
- [ ] 에러 처리 로직을 명확하게 작성하여 코드의 가독성을 높인다.
- [ ] 반복되는 컴포넌트와 스타일은 분리하여 재사용성을 높인다.

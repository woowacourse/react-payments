# 페이먼츠 미션

## 기능 요구사항

### 카드 번호 입력 및 식별

- [ ] 사용자는 카드 번호를 입력할 수 있다.
- [ ] 입력한 카드 번호가 Visa 또는 MasterCard에 해당하는 경우, 해당 브랜드의 로고가 UI에 표시된다.
- [ ] 카드 번호는 양의 정수만 입력할 수 있다.
- [ ] 올바르지 않은 입력을 한 경우 피드백을 제공하고 입력을 제한한다.
- [ ] 사용자의 카드 번호 입력에 따라 카드 프리뷰를 동시에 업데이트한다.

### 카드 유효기간 입력

- [ ] 사용자는 월과 년도를 입력할 수 있다.
  - [ ] 월의 경우 1부터 12까지의 2자리의 정수이다.
  - [ ] 년도의 경우 2자리의 양의 정수이다.
  - [ ] 올바르지 않은 입력을 한 경우 피드백을 제공하고 입력을 제한한다.
- [ ] 사용자의 카드 유효기간 입력에 따라 카드 프리뷰를 동시에 업데이트한다.

### 카드 CVC 입력

- [ ] 사용자는 CVC 번호를 입력할 수 있다.
  - [ ] CVC 번호는 000 - 999 까지의 3자리 정수이다.
  - [ ] 올바르지 않은 입력을 한 경우 피드백을 제공하고 입력을 제한한다.
- [ ] 사용자의 카드 CVC 입력에 따라 카드 프리뷰를 동시에 업데이트한다.

# 구현할 기능 목록
## 카드 브랜드 검증
- 카드사 식별 규칙 적용 - 가변 길이 지원
  - Visa, Master (기존 유지, 16자리)
  - Diners: 36으로 시작 (14자리)
  - AMEX: 34, 37로 시작 (15자리)
  - UnionPay: 622126~622925, 624~626, 6282~6288로 시작 (16자리)
- 동적 자릿수 및 포커스 처리
- 브랜드 식별 시, 해당 카드의 최대 길이에 맞춰 폼의 maxLength 동적 제한 필요
- 4자리 고정 포커스 이동 로직을 가변 길이에 맞게 수정 (AMEX는 4,6,5 배열, Diners는 4,6,4 배열)

## 카드사 선택 컴포넌트
- 사용자가 직접 카드사를 선택하는 UI 제공
- 선택 시 프리뷰 카드의 배경색 변경

## 비밀번호 입력 컴포넌트
- 카드 비밀번호 앞 2자리 입력 폼 구현
- 입력값 마스킹 처리 및 에러 피드백

## 상태 제어 및 동적 UI
- 상태 끌어올리기
- 개별 컴포넌트의 에러/입력 상태를 App에서 통합 관리
- 폼 전체의 유효성을 파악할 수 있는 파생 상태
- 유효성에 따른 점진적 폼 노출
- 현재 화면에 노출된 폼이 유효성 검사를 통과해야만 다음 입력 폼 렌더링
- 노출 시퀀스: 카드 번호 -> 카드사 선택 -> 유효기간 -> CVC -> 비밀번호 -> 확인 버튼

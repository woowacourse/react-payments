# 페이먼츠 1단계 - Component & Storybook

## 기능 구현 목록

- 결제할 카드 번호입력
  - 결제할 번호를 4자리 씩, 총 16개 입력한다.
  - 지원하지 않는 카드 브랜드의 구분 숫자일 경우, 에러 메세지를 띄운다.

- 카드 유효기간 입력
  - 월 두자리 01~12 범위의 숫자를 입력받는다.
  - 년도 두자리 숫자를 입력받는다.
  - 유효하지 않는 숫자를 입력할 경우, 에러 메세지를 띄운다.

- cvc 번호 입력
  - 세 자리 숫자를 입력받는다.

- 카드 브랜드 구분
  - Visa: 4로 시작하는 16자리 숫자
  - MasterCard: 51-55로 시작하는 16자리 숫자

- 카드 UI
  - 입력하는 카드 번호를 실시간으로 반영한다. 단, 9자리 부터는 "." 으로 대체한다.
  - 구분 숫자에 해당하는 브랜드의 로고를 반영한다.

# 페이먼츠 2단계 - hooks & state

## 기능 구현 목록

- 폼 제출 버튼
  - 모든 카드 정보가 정확하게 입력되면 버튼이 활성화된다
  - 입력 정보가 유효하지 않으면 버튼이 비활성화 된다.

- 카드 등록 완료 페이지
  - 폼 제출을 완료하면 사용자는 카드 등록 완료 페이지로 이동한다.
  - 카드시작 번호, 카드 종류를 알려주며 등록됐다는 메시지를 띄운다.
  - 다시 카드 등록 페이지로 돌아갈 수 있는 확인 버튼을 제공한다.

- 카드 등록 완료 확인 버튼
  - 다시 카드 등록 페이지로 돌아간다.

- 동적 입력 UI 구현
  - 카드 번호 입력 -> 카드사 선택 -> 카드 유효기간 입력 -> CVC 번호 입력 -> 비밀번호 입력 순으로 UI가 보여진다
  - 입력이 올바르게 완료되면 다음 입력 필드로 자동으로 이동한다.

- 카드사 선택
  - 카드사 를 선택하는 셀렉트 박스를 구현한다
  - 카드사 종류 : BC, 신한, 카카오뱅크, 현대, 우리, 롯데, 하나, 국민
  - 카드사에 선택에 따라 카드 색을 적용한다.

- 카드 브랜드 지원 확대
  - 기존 : visa, mastercard
  - 추가 : AMEX, Diners, UnionPay
  - 카드 브랜드 구분 로직
    - Diners: 36으로 시작하는 14자리 숫자
      - 예시: 3612 345678 9012
    - AMEX: 34, 37로 시작하는 15자리 숫자
      - 예시 (34로 시작): 3412 345678 90123
      - 예시 (37로 시작): 3712 345678 90123
    - 유니온페이: 카드의 앞 번호가 아래 3가지 조건을 만족하는 16자리 숫자
      - 622126~622925로 시작하는 경우: 6221 2612 3456 7890
      - 624~626로 시작하는 경우: 6240 1234 5678 9012
      - 6282~6288로 시작하는 경우: 6282 1234 5678 9012

# 페이먼츠 2단계 - hooks & state

## 기능 구현 목록

### 카드 번호 입력

- 4자리씩 총 16자리를 입력받는다.
- 입력 완료 시 다음 입력 필드로 자동으로 포커스가 이동한다.
- 숫자 외 문자는 입력되지 않는다.
- 유효하지 않은 값 입력 시 에러 메시지를 표시한다.

### 카드사 선택

- 카드 번호 입력 시 카드사를 선택할 수 있는 UI를 제공한다.
- 선택한 카드사에 따라 카드 프리뷰의 색상이 변경된다.

### 카드 브랜드 구분

- Visa: 4로 시작하는 16자리 숫자
- MasterCard: 51~55로 시작하는 16자리 숫자
- AMEX: 34 또는 37로 시작하는 15자리 숫자
  - 예: 3412 345678 90123
- Diners: 36으로 시작하는 14자리 숫자
  - 예: 3612 345678 9012
- UnionPay: 아래 조건 중 하나를 만족하는 16자리 숫자
  - 622126~622925로 시작하는 경우
  - 624~626으로 시작하는 경우
  - 6282~6288로 시작하는 경우

### 카드 유효기간 입력

- 월은 01~12 범위의 두 자리 숫자를 입력받는다.
- 년도는 두 자리 숫자를 입력받는다.
- 유효하지 않은 값 입력 시 에러 메시지를 표시한다.

### CVC 번호 입력

- 세 자리 숫자를 입력받는다.
- 숫자 외 문자는 입력되지 않는다.
- 유효하지 않은 값 입력 시 에러 메시지를 표시한다.

### 카드 UI

- 입력하는 카드 정보를 실시간으로 카드 프리뷰에 반영한다.
- 카드 번호 9자리부터는 "."으로 대체하여 표시한다.
- 선택한 카드사의 로고를 반영한다.

### 폼 제출 및 상태 관리

- 모든 카드 정보가 유효하게 입력된 경우에만 확인 버튼이 활성화된다.
- 입력 정보 중 하나라도 유효하지 않게 되면 확인 버튼이 비활성화된다.

### 카드 등록 완료

- 확인 버튼 클릭 시 카드 등록 완료 페이지로 이동한다.
- 등록 완료 페이지에서는 성공 메시지와 함께 카드 등록 페이지로 돌아가는 확인 버튼을 제공한다.
